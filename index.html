Importar / Exportar dados

Importar lançamentos via CSV

O arquivo deve ter colunas com data do atendimento, nome completo, convênio e valor pago pela AMHPDF (cabeçalhos parecidos são reconhecidos automaticamente). Para Lotus e Pantheon, se houver uma coluna de médico solicitante ela também é aproveitada (opcional). Aceita datas em DD/MM/AAAA ou AAAA-MM-DD, e valores como 1234,56 ou 1234.56. Os descontos e o repasse de cada linha são calculados automaticamente pela fórmula da clínica escolhida abaixo.

Exportar backup completo

Gera um arquivo .json com os lançamentos das 3 clínicas — use para guardar uma cópia de segurança ou levar os dados para outro computador.

Importar backup completo

Carrega um arquivo .json exportado anteriormente. Atenção: isso substitui todos os dados atuais do sistema.

Zona de risco

Apaga permanentemente lançamentos. Recomendado exportar um backup antes de usar isto.

Relatório por médico

Reúne, em qualquer clínica (Lotus e Pantheon), todos os atendimentos encaminhados por um mesmo médico solicitante e o total de 10% a repassar a ele.
